## 2. O que permanece segredo industrial (não publicado, não inferível daqui)

A ausência dos itens abaixo é uma **decisão deliberada de proteção de segredo industrial** — não uma lacuna técnica, não um work-in-progress, não material a ser publicado futuramente neste repositório:

| Elemento protegido | Razão |
|---|---|
| Código-fonte de gates, validadores, pipeline e scripts internos | Núcleo operacional proprietário |
| Prompts internos completos ou variações de prompts | Propriedade intelectual central |
| Dataset integral do benchmark (casos, verdades-base, saídas brutas) | Ativo de avaliação proprietário |
| Critérios específicos de bloqueio, thresholds e autorização | Diferencial técnico do método |
| Lógica operacional detalhada dos gates (sequência, condições, exceções) | Segredo industrial |
| Toolkit profissional para compradores e licenciados | Produto comercial |
| Capítulos do livro associado ao método | Obra literária em desenvolvimento |
| Termos comerciais, precificação e estratégia de monetização | Informação comercial sigilosa |
| Logs brutos do run BEORYS-PCT v0.2 e saídas individuais dos modelos | Evidência bruta protegida |
| Hash-mestre privado do run v0.2 (em custódia da titular) | Âncora de auditoria |
