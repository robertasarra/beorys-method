## 3. Procedimento de verificação

1. Clonar ou baixar o repositório
2. Para cada arquivo listado na seção 2, calcular SHA-256 localmente
3. Comparar com os hashes em `(SHA256_REGISTRY.md)`
4. Qualquer divergência indica alteração após a geração deste registro

Comando de verificação (Unix):
```bash
sha256sum <arquivo>
```
